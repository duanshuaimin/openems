# OpenEMS (Open Energy Management System)

OpenEMS is a modular platform for energy management applications.

## Getting Started

- Official Website: [https://openems.io](https://openems.io)
- Community Forum: [https://community.openems.io](https://community.openems.io)
- Official Documentation: [https://openems.github.io/openems.io/openems/latest/index.html](https://openems.github.io/openems.io/openems/latest/index.html)

## Repository Structure

- `edge`: Energy management edge controller runtime
- `backend`: Distributed management and aggregation server
- `ui`: Web-based dashboard and configuration UI
